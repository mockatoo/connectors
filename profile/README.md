## OAuth testing without the friction

Mockatoo replaces live social providers outside production while keeping your app's normal OAuth flow. Build and test sign-in without app registration, CAPTCHA, bot checks, or fragile browser workarounds.

- **Headless-browser friendly** for Playwright, CI, and automated tests.
- **Stable test flows** with semantic HTML and generous rate limits.
- **Agent-friendly development** without MFA, proof-of-work, or automated bot detection.
- **Simple integration** with Better Auth, Auth.js, and existing OAuth flows.
